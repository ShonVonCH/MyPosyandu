Langkah-langkah Menjalankan Aplikasi
1. Download code dalam bentuk file zip
2. Extract file zip menjadi folder lalu open folder di android studio
3. Sync Gradle di file build.gradle.kts
4. (Opsi 1)Pilih Build di bagian atas android studio lalu Generate App Bundles or APKs
5. Download aplikasi di device android lalu jalankan
6. (Opsi 2) Run aplikasi dari android studio lalu aplikasi akan langsung dijalankan di emulator(tidak disarankan karena aplikasi dapat crash di emulator)
7. (Opsi 3) Pair device android dengan android studio menggunakan kabel data atau QR jika berada di jaringan yang sama setelah itu run aplikasi dari android studio aplikasi dan aplikasi akan langsung terinstall dan berjalan di device android tersebut.
